## 平台简介

LangChain 工具平台是一个用于管理和共享 LangChain 工具的内部平台。您可以：

- 📤 **上传工具** - 将您编写的 LangChain 工具分享给团队
- 🔍 **浏览工具** - 查看平台上所有可用的工具
- 🧪 **测试工具** - 在线测试工具功能
- 🤖 **MCP 调用** - 通过 MCP 协议让 AI 助手调用工具

## 上传工具

### 步骤说明

1. **进入上传页面**
   - 点击左侧菜单「➕ 上传工具」

2. **填写基本信息**
   - **工具名称**（必填）：给工具起一个唯一的名称，如 `calculator`、`weather_query`
   - **工具描述**（可选）：描述工具的功能
   - **上传者**（可选）：填写您的名字

3. **粘贴源代码**
   - 将您的 Python 工具代码粘贴到代码框中

4. **验证代码**
   - 点击「🔍 仅验证」按钮检查代码是否符合规范
   - 系统会告诉您代码是否有效，如果无效会给出修改建议

5. **提交上传**
   - 验证通过后，点击「📤 上传工具」按钮完成上传

> 提示：工具名称需唯一，docstring 描述越具体，AI 越容易正确调用；验证失败时先用「仅验证」查看错误和建议。

### 上传结果

| 状态 | 说明 |
|------|------|
| 🟢 valid | 工具验证通过，可正常使用 |
| 🔴 invalid | 验证失败，请根据提示修改代码 |
| 🟡 pending | 等待验证 |
| ⚫ disabled | 工具已被禁用 |

## 工具规范

平台支持两种 LangChain 工具格式：

### 方式一：使用 @tool 装饰器（推荐）

这是最简单的方式，适合快速创建工具。

```python
from langchain_core.tools import tool

@tool
def my_tool(param1: str, param2: int = 10) -> str:
    """工具的描述信息（必须有！）
    
    这里详细描述工具的功能，AI 会根据这个描述来决定何时使用工具。
    
    Args:
        param1: 参数1的说明
        param2: 参数2的说明，默认值为10
    
    Returns:
        返回结果的说明
    """
    # 您的业务逻辑
    result = f"处理 {param1}，数量 {param2}"
    return result
```

**必须满足的要求：**
- ✅ 导入语句：`from langchain_core.tools import tool`
- ✅ 使用 `@tool` 装饰器
- ✅ 函数必须有 **docstring**（三引号字符串描述）
- ✅ 参数必须有 **类型注解**（如 `param1: str`）
- ✅ 返回值必须有 **类型注解**（如 `-> str`）

### 方式二：继承 BaseTool 类

适合需要更多自定义的复杂工具。

```python
from langchain_core.tools import BaseTool
from pydantic import BaseModel, Field
from typing import Type

# 定义输入参数模型
class MyToolInput(BaseModel):
    """输入参数定义"""
    query: str = Field(description="查询内容")
    limit: int = Field(default=10, description="返回数量限制")

# 定义工具类
class MyTool(BaseTool):
    """工具类的描述"""
    
    name: str = "my_tool"  # 工具名称（必须）
    description: str = "这个工具用于..."  # 工具描述（必须）
    args_schema: Type[BaseModel] = MyToolInput  # 参数模式（推荐）
    
    def _run(self, query: str, limit: int = 10) -> str:
        """执行工具的主要逻辑（必须实现）"""
        # 您的业务逻辑
        return f"查询 {query}，限制 {limit} 条"
    
    async def _arun(self, query: str, limit: int = 10) -> str:
        """异步执行（可选）"""
        return self._run(query, limit)
```

**必须满足的要求：**
- ✅ 导入语句：`from langchain_core.tools import BaseTool`
- ✅ 类继承 `BaseTool`
- ✅ 定义 `name` 属性
- ✅ 定义 `description` 属性
- ✅ 实现 `_run` 方法

## 工具示例

### 示例1：计算器工具

```python
from langchain_core.tools import tool

@tool
def calculator(expression: str) -> str:
    """计算数学表达式的值
    
    可以计算加减乘除、括号等基本数学运算。
    
    Args:
        expression: 数学表达式，如 "2 + 3 * 4" 或 "(10 - 5) / 2"
    
    Returns:
        计算结果
    """
    try:
        # 安全地计算表达式
        allowed_chars = set('0123456789+-*/().% ')
        if not all(c in allowed_chars for c in expression):
            return "错误：表达式包含非法字符"
        
        result = eval(expression)
        return f"计算结果：{result}"
    except Exception as e:
        return f"计算错误：{str(e)}"
```

### 示例2：文本处理工具

```python
from langchain_core.tools import tool

@tool
def text_processor(text: str, operation: str = "count") -> str:
    """文本处理工具
    
    对文本进行各种处理操作。
    
    Args:
        text: 要处理的文本内容
        operation: 操作类型，可选值：count（统计字数）、upper（转大写）、lower（转小写）、reverse（反转）
    
    Returns:
        处理后的结果
    """
    operations = {
        "count": lambda t: f"字符数：{len(t)}，单词数：{len(t.split())}",
        "upper": lambda t: t.upper(),
        "lower": lambda t: t.lower(),
        "reverse": lambda t: t[::-1]
    }
    
    if operation not in operations:
        return f"不支持的操作：{operation}，可选：{list(operations.keys())}"
    
    return operations[operation](text)
```

### 示例3：JSON 格式化工具

```python
from langchain_core.tools import tool
import json

@tool
def json_formatter(json_string: str, indent: int = 2) -> str:
    """JSON 格式化工具
    
    将 JSON 字符串格式化为易读的形式。
    
    Args:
        json_string: 要格式化的 JSON 字符串
        indent: 缩进空格数，默认为2
    
    Returns:
        格式化后的 JSON 字符串
    """
    try:
        data = json.loads(json_string)
        return json.dumps(data, indent=indent, ensure_ascii=False)
    except json.JSONDecodeError as e:
        return f"JSON 解析错误：{str(e)}"
```

## 使用工具

### 在平台上测试

1. 打开「🔍 测试工具」页面（列表仅展示状态为 valid 的工具）
2. 选择工具后，会自动展示工具描述与按 `input_schema` 生成的参数表单（带 * 的为必填）
3. 填写参数，可选填写调用者名称
4. 点击「🚀 执行工具」查看返回结果与耗时
5. 如果执行失败，可返回「工具列表」查看验证信息或重新上传

### 通过 API 管理工具

```python
import requests

API_URL = "http://localhost:7000/api"

source_code = """
from langchain_core.tools import tool

@tool
def ping() -> str:
    '''简单连通性检测'''
    return "pong"
"""

# 1) 仅验证代码
validation = requests.post(
    f"{API_URL}/tools/validate",
    params={"source_code": source_code}
).json()
print(validation)

# 2) 创建/上传工具（名称需要唯一）
created = requests.post(
    f"{API_URL}/tools/",
    json={
        "name": "ping",
        "description": "示例工具",
        "source_code": source_code,
        "uploader": "Alice"
    }
).json()
print(created)

# 3) 按状态或关键词过滤工具
tools = requests.get(
    f"{API_URL}/tools/",
    params={"status": "valid", "search": "calc"}
).json()
print(tools)
```

常用状态值：`valid`、`invalid`、`pending`、`disabled`。

### 通过 API 调用

```python
import requests

# API 地址
API_URL = "http://localhost:7000/api"

# 1. 查看可用工具
tools = requests.get(f"{API_URL}/mcp/tools").json()
print("可用工具：", [t["name"] for t in tools])

# 1.1 查看单个工具的输入 Schema
calculator = requests.get(f"{API_URL}/mcp/tools/calculator").json()
print(calculator)

# 2. 调用工具
response = requests.post(
    f"{API_URL}/mcp/call",
    json={
        "tool_name": "calculator",
        "arguments": {
            "expression": "2 + 3 * 4"
        },
        "caller": "张三"  # 可选，记录调用者
    }
)

result = response.json()
if result["success"]:
    print("结果：", result["result"])
else:
    print("错误：", result["error"])
```

## MCP 集成

### 什么是 MCP？

MCP（Model Context Protocol）是一种让 AI 模型调用外部工具的协议。通过 MCP，您可以让 Claude、ChatGPT 等 AI 助手使用平台上的工具。

### MCP 服务地址

```
http://localhost:7000/api/mcp
```

### MCP 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/mcp/tools` | GET | 获取所有可用工具 |
| `/api/mcp/tools/{tool_name}` | GET | 获取单个工具信息（含 inputSchema） |
| `/api/mcp/call` | POST | 调用指定工具 |
| `/api/mcp/tools/{tool_name}/call` | POST | 按路径调用指定工具 |
| `/api/mcp/protocol/info` | GET | 获取服务信息 |
| `/api/mcp/protocol/tools/list` | POST | 列出工具（MCP标准格式） |
| `/api/mcp/protocol/tools/call` | POST | 调用工具（MCP标准格式） |

### 在 AI 应用中使用

```python
from langchain_core.tools import StructuredTool
import requests

def create_remote_tool(tool_info):
    """从远程 MCP 服务创建工具"""
    def call_remote(**kwargs):
        response = requests.post(
            "http://localhost:7000/api/mcp/call",
            json={
                "tool_name": tool_info["name"],
                "arguments": kwargs
            }
        )
        result = response.json()
        return result["result"] if result["success"] else result["error"]
    
    return StructuredTool.from_function(
        func=call_remote,
        name=tool_info["name"],
        description=tool_info["description"]
    )

# 获取远程工具列表
tools_info = requests.get("http://localhost:7000/api/mcp/tools").json()

# 创建可用于 LangChain Agent 的工具
remote_tools = [create_remote_tool(t) for t in tools_info]
```

## 常见问题

### Q: 上传的代码验证失败怎么办？

**A:** 请检查以下几点：
1. 是否有正确的导入语句
2. 函数/类是否有完整的 docstring
3. 参数和返回值是否有类型注解
4. 如果是 BaseTool 类，是否定义了 name、description 和 _run 方法

系统会给出具体的错误信息和修改建议，请按照提示修改。

### Q: 工具状态显示 invalid，但我确认代码是正确的？

**A:** 可以尝试：
1. 在「工具列表」中找到该工具
2. 点击「查看详情」查看具体的验证错误信息
3. 如果确认代码正确，可以更新代码后重新验证

### Q: 如何修改已上传的工具？

**A:** 
1. 在「工具列表」中找到要修改的工具
2. 点击「查看详情」
3. 目前需要删除后重新上传，后续版本会支持在线编辑

### Q: 工具可以调用外部 API 吗？

**A:** 可以。工具代码中可以使用 `requests` 等库调用外部 API。但请注意：
- 确保网络可访问
- 处理好超时和异常
- 不要在代码中硬编码敏感信息（如 API Key）

### Q: 如何查看工具的调用记录？

**A:** 在「📊 统计信息」页面可以查看：
- 各工具的调用次数
- 工具状态分布
- 整体统计数据

### Q: 工具执行超时怎么办？

**A:** 工具执行有时间限制。如果您的工具需要较长时间：
1. 优化代码执行效率
2. 考虑将耗时操作异步化
3. 对于特别耗时的任务，考虑拆分成多个工具

## 最佳实践

### 1. 写好工具描述

工具的 docstring 非常重要，AI 会根据描述来决定是否使用工具。

```python
# ❌ 不好的描述
@tool
def process(data: str) -> str:
    """处理数据"""
    ...

# ✅ 好的描述
@tool
def format_phone_number(phone: str) -> str:
    """格式化中国手机号码
    
    将各种格式的手机号码统一格式化为 xxx-xxxx-xxxx 格式。
    支持带空格、横线或不带分隔符的输入。
    
    Args:
        phone: 手机号码，如 "13812345678" 或 "138 1234 5678"
    
    Returns:
        格式化后的手机号，如 "138-1234-5678"
    """
    ...
```

### 2. 处理异常情况

```python
@tool
def divide(a: float, b: float) -> str:
    """除法计算"""
    try:
        if b == 0:
            return "错误：除数不能为零"
        return str(a / b)
    except Exception as e:
        return f"计算错误：{str(e)}"
```

### 3. 参数有默认值时要说明

```python
@tool
def search(query: str, limit: int = 10, lang: str = "zh") -> str:
    """搜索内容
    
    Args:
        query: 搜索关键词
        limit: 返回结果数量，默认10条
        lang: 语言，默认中文(zh)，可选英文(en)
    """
    ...
```
